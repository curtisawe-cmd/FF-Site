Extra snapshot rows

Three of your own lines on the Home page's League Snapshot — buy-in, trade deadline, punishment for last place, whatever. Leave a row blank to hide it.

Prize Money

Buy-in per manager sets the pot. Division winners get their buy-in back; the podium payouts below are placeholders — edit them to match your league.

Commissioners

Commissioners can edit league settings, run the draft, and manage every team. Only the league owner can add or remove commissioners.

League Managers

The master roster of everyone who manages a team. Edit a name to fix it everywhere; remove someone to free them up. This list fills the manager dropdown on each team below.

Teams & Draft Order

Order below = round 1 pick order (snakes every round). Check auto for any manager who can’t attend — auto teams draft themselves: starters first (QB, 2 RB, 2 WR, TE, flex, K, DEF), then best available. The commissioner still makes auto teams’ keeper-round picks.

Adding a team creates an open slot; removing trims from the bottom.

Alarms & noise

Draft Alarm Insults

When someone tries an illegal draft pick, one of these gets screamed at them. One line per insult — type whatever you want. Write {mgr} for the manager on the clock, {team} for their team, {player} for whoever they tried to draft and {pos} for the position; each alarm fills in the real ones, and a line with no tokens shows as-is. {mgr} falls back to the team name for anyone without a manager set. Leave it blank to use the built-in set.

Trade Alarm Lines

When a trade gets accepted, this screams across everyone's screen. One line per message — type whatever you want. Leave it blank to use the built-in set. Write {a} and {b} where the two teams' names should go (or {teams} for both at once) and each alarm fills in the actual teams — a line with no tokens shows as-is.

Keeper Alarm Lines

A manager can only keep the same player one year. If a keeper-round pick lands on somebody that same manager already kept last season, this screams across the screen — a different manager keeping him is fine and stays quiet. The pick still goes through: a name that doesn't match the imported list exactly must never be able to halt a live draft, so the alarm tells the room and the call stays yours. One line per message. Write {p} for the player, {team} for whoever kept him and {y} for the year. Leave blank for the built-in set.

Mock Draft Trash Talk

The slam animation when a mock draft gets reset. One message per line. Use a | to split the big top line from the small subtitle, e.g. DON'T BE A BITCH | use these picks, pussy. Leave blank for the built-in set.

Tab Flash 🔒

Full-screen message for 1.7s on every Nth tab click. One per line; blank = off.
